About, Methodology & Viva Guide

Theoretical foundations, dataset provenance, mathematical formulation, and technical questions for academic defense.

1. Project Objective & Core Philosophy

The primary goal of this application is to analyze news articles using genuine machine learning methods and predict whether their syntactic and lexical structure closely resembles verified journalism or fabricated stories in standard benchmark research datasets.

⚠️
Linguistic Style vs. Factual Ground Truth: A machine learning NLP model evaluates how a story is written, not whether the real-world events described actually happened. True news written in an eccentric tone may resemble fake news, while polished propaganda written in standard journalistic English may deceive the classifier. The model never connects to external fact databases or proves factual truth.

2. Mathematical Formulation

A. TF-IDF Vectorization

Converts text tokens and bigrams into numerical importance weights:

TF(t, d) = 1 + log(ft,d) [sublinear TF]

IDF(t, D) = log((1 + |D|) / (1 + |{d ∈ D : t ∈ d}|)) + 1

TF-IDF(t, d, D) = TF(t, d) × IDF(t, D)

Penalizes ubiquitously frequent English words (e.g., "said", "the", "report") while emphasizing distinctive, topical vocabulary.

B. Logistic Regression Classifier

Maps high-dimensional sparse TF-IDF vectors into a posterior probability:

z = wT x + b

P(Real | x) = σ(z) = 1 / (1 + e-z)

Loss = -[y log(σ(z)) + (1-y) log(1-σ(z))] + (λ/2) ||w||2

L2 regularization prevents overfitting on rare n-grams. The sigmoid σ(z) outputs calibrated probabilities.

4. College Viva & Technical Defense Q&A

Q1: Why did you choose TF-IDF with Logistic Regression instead of CountVectorizer or Naive Bayes?

CountVectorizer treats all words proportionally to their raw count, allowing frequent boilerplate words to dominate the feature space. TF-IDF scales down universally common terms and highlights domain-specific markers. Logistic Regression handles high-dimensional sparse representations (50,000 n-grams) gracefully with L2 regularization and produces calibrated, smooth probability outputs compared to Multinomial Naive Bayes, which suffers from independence assumptions.

Q2: How is data leakage prevented between training and testing?

Data leakage occurs when information from outside the training dataset is used to create the model. In this pipeline, train_test_split is performed strictly before any vectorizer fitting. The TF-IDF vectorizer vocabulary and IDF weights are computed exclusively on X_train using a Scikit-Learn Pipeline. The test set is treated as unseen holdout data, ensuring the reported test accuracy is completely unbiased.

Q3: Why not deploy a 10-billion parameter Large Language Model (LLM) or BERT for this?

For a production or college-level deployment, TF-IDF + Logistic Regression delivers sub-millisecond inference time on CPU with zero GPU dependencies, requires negligible RAM (~20 MB vs >8 GB), and provides transparent mathematical interpretability through direct inspection of feature weights (coefficients).

Q4: What are the main limitations of this system?

1. Temporal Drift: New political events and named entities emerge that were not present in the 2016-2021 training corpus.
2. Adversarial Paraphrasing: False statements written in formal, dry journalistic language will be classified as "Likely Real" because the model assesses syntax, not facts.
3. Satire and Parody: Satirical news (such as The Onion) often mimics real journalistic structure intentionally, confusing the classifier.
